I created this project during my second year of 6th form as we were assigned to create a text adventure game, since then i have went back and changed it, stripping out the game like features, keeping the underlying trading essence and polishing it up.

Here is some screenshots of it working, some stocks work better than other as market trends are unpredictable, eg. for tesla, the company was in its early stages and had a huge boom in 2020 which the monte carlo simulation cannot predict.
